# 03 · 测试指南

> 12 步真机验证法 + 性能基线 + CI 门禁
>
> 核心原则：**每完成一个最小可验证单元，就在真机上跑通一次**。不攒代码、不堆功能、不硬撑。

## 一、每步完成定义（DoD）

每一步必须满足以下 4 条才算通过，少一条不进入下一步：

1. **功能跑通**：达到该步的验证标准（真机实测）；
2. **日志可见**：所有错误有清晰的 UI 展示，不是黑屏/闪退；
3. **有回退 tag**：`git tag stepX-ok`，随时能切回去；
4. **CI 过门禁**：该步对应的自动化测试通过（如已有）。

## 二、12 步真机验证清单

### Step 1 · proot + rootfs Hello World

**目标**：验证地基——proot 能正常启动最小 Debian rootfs。

**验证项**：
- [ ] 首次启动能成功解压 rootfs（不崩溃、进度正确）
- [ ] `proot` 启动后执行 `echo hello` 正常输出
- [ ] `uname -a` 输出 Linux 内核信息（aarch64）
- [ ] `apt --version` 正常输出
- [ ] 杀掉 App 重进，rootfs 保留不重建
- [ ] 至少 2 款不同安卓版本手机通过

**失败回退**：无（第 1 步）

---

### Step 2 · 文件树 + 代码编辑器

**目标**：最小可用编辑器，能看能改。

**验证项**：
- [ ] 创建/删除/重命名文件正常
- [ ] 打开 500 行 Dart 文件，滚动流畅、输入无明显延迟
- [ ] Dart 语法高亮正确
- [ ] 中文输入正常，软键盘弹出不挤压布局
- [ ] 后台切回 App，光标位置和内容保留
- [ ] 平板 / 横屏适配正常（可选，有平板时测）

**失败回退**：`git tag step1-ok`

---

### Step 3 · JDK 安装验证

**目标**：JDK 17 在 proot 内可用。

**验证项**：
- [ ] 下载 + 解压 + SHA-256 校验全流程正常
- [ ] 断点续传功能生效（手动断网测试）
- [ ] `java -version` 输出正确版本
- [ ] 写一个 Hello.java，`javac` 编译 + `java` 运行通过
- [ ] 4GB 内存手机安装过程不 OOM、不闪退
- [ ] 卸载重装功能正常

**失败回退**：`git tag step2-ok`

---

### Step 4 · Flutter SDK 安装

**目标**：Flutter SDK 在 proot 内"活了"。

**验证项**：
- [ ] Flutter SDK 下载解压成功（国内镜像）
- [ ] `flutter --version` 正常输出
- [ ] `flutter doctor` 跑完（Android 项缺失属正常）
- [ ] `flutter create test_proj` 能成功创建默认项目
- [ ] `dart --version` 正常
- [ ] `flutter pub get` 在默认项目上成功

**失败回退**：`git tag step3-ok`

---

### Step 5 · Web 预览（热重载）⭐ 里程碑

**目标**：第一次"写代码 → 看效果"闭环。

**验证项**：
- [ ] `flutter run -d web-server` 启动成功
- [ ] App 内 WebView 打开 `localhost:8080` 正常显示默认计数器
- [ ] 点击 + 号数字 +1，交互正常
- [ ] 修改 `lib/main.dart` 保存，热重载在 2 秒内生效
- [ ] 退出 App 再进，能重新拉起预览（进程状态检测）
- [ ] 日志面板显示构建/预览日志

**失败回退**：`git tag step4-ok`

---

### Step 6 · cmdline-tools + aapt2 替换

**目标**：Android SDK 工具链就绪，aapt2 替换生效。

**验证项**：
- [ ] cmdline-tools 下载安装成功（用户确认流程）
- [ ] `sdkmanager --version` 正常
- [ ] `sdkmanager "platforms;android-XX"` 安装成功
- [ ] `aapt2 version` 输出版本号（证明 ARM64 版在工作）
- [ ] `flutter doctor --android-licenses` 能跑完（yes 管道自动接受）
- [ ] `flutter doctor` Android 项全绿（除了 Android Studio not found）

**失败回退**：`git tag step5-ok`

### Step 7 · Debug APK 构建⭐ 里程碑

**目标**：手机上第一次出真 APK。

**验证项**：
- [ ] 默认计数器 App 完整构建 debug APK，无报错
- [ ] 构建日志实时显示在 UI 上
- [ ] `PackageInstaller` intent 弹出安装界面
- [ ] 安装后 App 正常启动、运行
- [ ] 构建期间 App 不崩溃、通知栏进度正常
- [ ] 构建可中途取消

**失败回退**：`git tag step6-ok`

### Step 8 · 增量构建 & 性能基线

**目标**：建立性能基线，后续每版对比。

**验证项（3 档机型各测 3 次取平均）**：
- [ ] 冷构建耗时（`flutter clean` 后第一次构建）
- [ ] 增量构建耗时（改一行 Dart 代码后构建）
- [ ] 峰值内存（`dumpsys meminfo` 最高点）
- [ ] 电池温升（构建前后温差）
- [ ] 构建期间前台服务保活正常，不被系统杀掉
- [ ] 配置缓存、构建缓存正常工作（二次构建明显更快）

**记录到性能基线表**（见附录 A）

**失败回退**：`git tag step7-ok`

- [ ] 无 `Flag dedup_instructions is false` 崩溃（gen_snapshot 验证）

- [ ] 旧版本卸载功能正常

## 四、CI 自动化门禁

### 必跑（每次 push）

- `flutter analyze` — 静态分析
- `flutter test` — 单元测试
- 构建 community flavor APK 成功

### 每日定时

- arm64 runner 冒烟测试：rootfs 组装 → JDK → Flutter SDK → debug 构建 → 断言产物存在且签名有效
- 许可证扫描（ScanCode），发现未知 GPL 组件告警

### 发版前

- 全量 12 步回归（真机）
- 性能基线对比
- 许可证合规检查清单（见 05 号文档）

## 五、测试工具速查

```bash
# 日志
adb logcat -c                    # 清空日志
adb logcat | grep flutter        # 过滤 Flutter 日志
adb logcat -s AndroidRuntime:D   # 只看 AndroidRuntime crash

# 内存
adb shell dumpsys meminfo <pkg>
adb shell top -m 10

# 电池/温度
adb shell dumpsys battery
adb shell cat /sys/class/thermal/thermal_zone0/temp
adb shell cat /sys/class/thermal/thermal_zone*/type

# 构建耗时测量（在 proot 内执行）
time flutter build apk --debug --target-platform=android-arm64

# APK 信息
apksigner verify --verbose app-release.apk
aapt dump badging app-release.apk | head -20
```
