# 开发手册（Dev Handbook）

> 本手册是安卓端 Flutter IDE 项目的**唯一权威知识源**，记录环境搭建、构建流程、测试方法、Bug 解决方案、许可证合规与发布规范。
>
> 每遇到一个新坑、每解决一个问题，都必须**第一时间更新到对应文档**，不要相信记忆力。

## 项目核心原则

1. **每完成一步必真机验证**——不攒代码、不堆功能，垂直切片式推进；
2. **Bug 解决后必写文档**——每个坑至少有一个"症状 → 原因 → 解决"记录；
3. **许可证红线不可碰**——新依赖引入前必须过 05 号文档的检查清单；
4. **回退比硬撑重要**——每步打 tag，出问题 5 分钟内回退到上一个稳定节点。

## 快速定位

- **构建报错**：先看 [04-常见Bug与解决方案.md](./04-常见Bug与解决方案.md)，按错误信息搜索；
- **不知道该测什么**：看 [03-测试指南.md](./03-测试指南.md) 对应 Step 的验证清单；
- **不确定某个依赖能不能用**：查 [05-许可证合规.md](./05-许可证合规.md) 的决策表；
- **环境搭不起来**：跟着 [01-环境搭建.md](./01-环境搭建.md) 一步步走。
