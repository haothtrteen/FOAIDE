# 01 · 环境搭建

> 开发机环境 + 项目初始化 + 真机调试配置

## 一、开发机环境（桌面端）

### 必备工具

| 工具 | 版本 | 说明 |
|---|---|---|
| Flutter SDK | stable（与 App 内构建版本一致） | 用于开发 App 本体 |
| Android Studio | 最新稳定版 | 提供 Android SDK、模拟器、adb |
| Git | 最新 | 版本控制 |
| VS Code / IntelliJ | 任选 | 编辑器 |

### 国内镜像配置（必做）

```bash
# ~/.bashrc 或 ~/.zshrc 末尾追加
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```

验证：

```bash
flutter doctor
# 检查 Android toolchain 是否全绿
```

## 二、项目初始化

### 仓库结构

```
app/                     # Flutter App 主工程（AGPL-3.0）
  lib/
    core/                # 编辑器、文件树、通用组件
    env/                 # proot 管理、rootfs 组装
    builder/             # 构建编排器
    plugins/             # 插件宿主与 SDK
    ui/                  # 页面与导航
  android/               # 安卓原生层
  assets/
    rootfs/              # rootfs 相关资源（运行时下载，不内置）
    tools/               # 预编译的 arm64 工具（aapt2、proot 等）
plugin-sdk/              # 插件 SDK（MIT，独立仓库或子模块）
backend/                 # 商城后端（专有，私有仓库）
dev-handbook/            # 本手册
```

### 初始创建命令

```bash
flutter create --org com.yourdomain --platforms=android app
cd app
flutter pub add re_editor re_highlight path_provider shared_preferences
```

### 原生权限

`android/app/src/main/AndroidManifest.xml` 需添加：

```xml
<!-- 网络：下载 SDK、Pub 依赖 -->
<uses-permission android:name="android.permission.INTERNET"/>
<!-- 存储：访问项目文件（Android 10+ 用 scoped storage） -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/>
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28"/>
<!-- 请求安装 APK -->
<uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES"/>
<!-- 前台服务：构建时保活 -->
<uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_SPECIAL_USE"/>
```

## 三、真机调试配置

### 手机端准备

1. 开启"开发者选项" → 打开"USB 调试"；
2. （推荐）打开"无线调试"，摆脱数据线；
3. 关闭"电池优化"中对本 App 的优化，避免构建时被杀。

### 连接方式

```bash
# USB 连接
adb devices

# 无线调试（Android 11+）
# 手机端：开发者选项 → 无线调试 → 使用配对码配对
adb pair <ip>:<port>
adb connect <ip>:<port>
```

### 常用调试命令

```bash
# 查看日志（过滤 Dart/Flutter 相关）
adb logcat | grep -E "flutter|Dart|AndroidRuntime"

# 查看应用内存
adb shell dumpsys meminfo <package_name>

# 查看电池/温度（构建压力测试用）
adb shell dumpsys battery
adb shell cat /sys/class/thermal/thermal_zone*/temp

# 安装/卸载 APK
adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb uninstall <package_name>

# 将文件推送到手机（测试 rootfs 等大文件时用）
adb push local_file /sdcard/
```

## 四、测试设备矩阵建议

| 档位 | 推荐机型参考 | Android 版本 | RAM | 目的 |
|---|---|---|---|---|
| 入门机 | 骁龙 6xx / 天玑 7xx 机型 | 9-10 | 4GB | 验证性能下限、OOM 风险 |
| 主力机 | 骁龙 8 Gen 1/2 | 13-14 | 8-12GB | 日常开发调试 |
| 旗舰机 | 最新骁龙 / 天玑旗舰 | 15-16 | 12GB+ | 验证性能上限、AVF 兼容性 |
| 平板 | 任意安卓平板 | 13+ | 6GB+ | 验证大屏适配 |

> **至少要有 2 台真机**：一台主力调试 + 一台入门机做性能基线。

## 五、CI/CD 环境（GitHub Actions）

公共仓库免费使用 arm64 跑机（`ubuntu-24.04-arm`），用于构建管线的自动化回归测试。工作流文件放在 `.github/workflows/` 下，至少包含：

- `lint_test.yml`：静态检查 + 单元测试（每次 push）
- `build_apk.yml`：构建 community flavor APK（PR 和 tag）
- `arm_smoke.yml`：arm64 runner 上跑 proot + flutter build 冒烟测试（每天定时 + tag）
- `license_scan.yml`：ScanCode 许可证扫描（每次引入新依赖时手动触发 + 每周定时）
